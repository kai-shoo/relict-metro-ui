# Visual Specifications for Windows Phone Toolkit

[Table of contents](../README.md) · [Component catalogue](components.md#windows-phone-toolkit-extensions) · [XAML theme and unit resources](foundations.md#phone-8-silverlight-geometry-and-theme-resources)

Here are the sizes, brushes and states of the Toolkit templates for Silverlight WP7 and WP8 projects from Microsoft source code. Numbers are given in XAML layout units. `Phone…` names refer to SDK theme resources, and literal numbers, colors, and transparency refer to the template. The size with the prefix `d:` acts in the designer. Markup of demonstrations is given with the sample name. ## LongListSelector and group overview

| --- | --- |

| `Small` | 99 × 99 |
| `Medium` | 210 × 210 |
| `Large` | 432 × 210 |

The standard background is `PhoneAccentBrush`, the text is white `#FFFFFFFF`. The front header uses Normal 41, line height 39, `10,0,0,6` indentations, and lower boundary alignment.
