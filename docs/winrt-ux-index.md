# Индекс UX Windows Runtime за апрель 2014

[Оглавление](../README.md) · [Архив Windows Phone](windows-phone-archive.md) · [Карта PDF 2014](sources.md#карта-pdf-2014)

В указателе MSDN от 6 апреля 2014 года 11 тематических разделов, вступительные материалы и два примера приложений. Всего 126 ссылок с 120 уникальными идентификаторами. По одному адресу могут идти материалы из нескольких разделов. Указатель охватывает Windows Store и Windows Phone Store. [Исходный индекс MSDN](https://web.archive.org/web/20140406143939id_/http://msdn.microsoft.com:80/en-us/library/windowsphone/design/hh465424.aspx)

Колонка MSDN сохраняет исходные адреса Microsoft. Для всех 126 позиций указан материал для чтения. Это снимки MSDN, публикации Microsoft Learn и страницы сверенного по контрольной сумме PDF. Пометка «По теме» указывает на связанный раздел PDF. [Руководство Microsoft, 447 страниц](https://tilsgee.github.io/DesignGuidelinesArchive/uwp8.1.pdf)
