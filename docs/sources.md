# Каталог первоисточников Microsoft

Проверено 19 ноября 2026 года. **Microsoft** означает публикацию на домене Microsoft или в её GitHub-репозитории. **Зеркало документа Microsoft** означает доступную копию материала с издательскими сведениями Microsoft. **Архивный снимок** обозначает копию исходного адреса Microsoft в Wayback Machine. Номера страниц ниже соответствуют печатной нумерации в PDF. В просмотрщике номер листа может отличаться.

[Архив Windows Phone Dev Center](windows-phone-archive.md) содержит отдельные тематические оглавления 2012 и 2014 годов и ссылки из MSDN Code Gallery.
