# Visual Specifications for Windows Phone 8.1 Store Apps

In Phone 8.1 Store apps, WinJS Pivot is CSS, while Hub and Pivot in XAML use phone theme resources. Each branch has its own units, fonts, indentations and states. Windows 8.1 desktop uses its own Hub. ## Phone Hub and Pivot in WinJS

The values are taken from the open audit of Microsoft Open Technologies on April 18, 2014. Its `package.json` lists a version of `2.0.1`, and the AppBar phone’s documentation lines refer to the `Microsoft.Phone.WinJS.2.1` system package. The exact numbers below describe an open audit. The byte correspondence of its LESS to the installed system package 2.1 remains unconfirmed.
