# Визуальные спецификации Windows Phone 8.1 Store apps

[Оглавление](../README.md) · [Компоненты](components.md#поверхности-windows-phone-81-xaml-и-winjs) · [Графические ресурсы](foundations.md#графика-phone-81-store-apps)

В Phone 8.1 Store apps WinJS Pivot оформляется в CSS, а Hub и Pivot в XAML используют ресурсы телефонной темы. У каждой ветки свои единицы, шрифты, отступы и состояния. Настольная ветка Windows 8.1 использует собственный Hub. [WinJS на Windows Phone 8.1](https://blogs.windows.com/windowsdeveloper/2014/04/18/winjs-on-windows-phone-8-1/) · [Сопоставление XAML для телефона и ПК](https://blogs.windows.com/windowsdeveloper/2014/07/22/tips-and-tricks-for-using-xaml-controls-in-your-universal-windows-apps/)

## WinJS Phone и Pivot

Значения взяты из открытой ревизии Microsoft Open Technologies от 18 апреля 2014 года. В её `package.json` указана версия `2.0.1`, а документационные строки телефонного AppBar ссылаются на системный пакет `Microsoft.Phone.WinJS.2.1`. Точные числа ниже характеризуют открытую ревизию. Побайтовое соответствие её LESS установленному системному пакету 2.1 остаётся неподтверждённым. [Версия репозитория](https://github.com/winjs/winjs/blob/12a81d41d6ee7f29ccf4d299154387f3acd8f1d1/package.json#L1-L4) · [Ссылки на телефонный пакет](https://github.com/winjs/winjs/blob/12a81d41d6ee7f29ccf4d299154387f3acd8f1d1/src/js/controls/AppBar/AppBar-phone.js#L19-L34)

[Заголовок Pivot](https://github.com/winjs/winjs/blob/12a81d41d6ee7f29ccf4d299154387f3acd8f1d1/src/less/styles-pivot.less#L12-L24) |

В телефонном AppBar CSS держит скрытый контейнер для компоновки. Панель рисует нативный `WebUICommandBar`, который открывается через `Windows.UI.WebUI.Core`. Режим закрытой панели по умолчанию `compact`. Геометрия видимой панели принадлежит платформе. [Телефонный LESS](https://github.com/winjs/winjs/blob/12a81d41d6ee7f29ccf4d299154387f3acd8f1d1/src/less/styles-appbar-phone.less#L2-L16) · [Нативный CommandBar](https://github.com/winjs/winjs/blob/12a81d41d6ee7f29ccf4d299154387f3acd8f1d1/src/js/controls/AppBar/AppBar-phone.js#L195-L205) · [Режим compact и minimal](https://github.com/winjs/winjs/blob/12a81d41d6ee7f29ccf4d299154387f3acd8f1d1/src/js/controls/AppBar/AppBar-phone.js#L414-L436)
